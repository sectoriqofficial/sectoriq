# SectorIQ

**Know exactly where you're losing time.**

SectorIQ is a free lap analysis tool for Assetto Corsa. It reads your session data automatically and shows you, sector by sector, exactly where you gained or lost time compared to your best lap.

## Why I built this

I play on a controller, not a wheel. Most sim racing coaching content assumes you're on a wheel setup, and I couldn't find anything that broke down *why* I was losing time in specific corners. So I built this for myself, then figured other controller players (or anyone without a coach) might find it useful too.

This isn't about an AI driving for you or telling you what to do. It's about seeing your own data clearly enough to figure out where to focus your practice.

## What it does

- Automatically reads your latest Assetto Corsa session (no manual file copying)
- Filters out invalid laps (track limit violations, incomplete laps)
- Shows sector-by-sector time gaps compared to your best lap
- Saves every session to a permanent history, so nothing is lost
- Tracks trends over time, compare cars on the same track, see if you're actually improving
- Exports your full history to Excel, with a native chart, if you want to dig into the data yourself

## Getting started

1. Download the latest release below
2. Run `SectorIQ.exe`
3. Play a session in Assetto Corsa, complete at least one clean lap
4. Click "Analyze Latest Session"

That's it. No installation, no setup files, no account needed.

## Requirements

- Windows
- Assetto Corsa (any version that saves session data to `Documents/Assetto Corsa/out/race_out.json`)
